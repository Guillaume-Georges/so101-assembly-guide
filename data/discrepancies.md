# Discrepancies between sources

Where two public sources disagree about the SO-101 build, the disagreement is
recorded here rather than silently resolved. Default preference: the upstream
TheRobotStudio spec, with the variant noted.

Format per entry:

```
## D-001 — <short title>
- Topic: <part / step / servo id>
- Source A: <ref> says …
- Source B: <ref> says …
- Resolution: <which we follow and why, or "open">
- Affects: <step ids>
```
